**The only bare-word ASTRAGAL registration is dead.** The word is a common architectural noun,
which is why nobody owns it in the trades — and that descriptiveness is exactly what makes it
*arbitrary*, and so registrable, in software.

> **Watch item:** ASTRAGAL PRESS is live in **Class 41 (publishing)**. It does not touch software,
> but Astragal is described internally as a *publisher* of software. Keep "publisher" as
> descriptive prose, not as a service claim, and do not file in Class 41.

### Trading namesake — the one real item

**[astragalhq.com](https://astragalhq.com)** — field-service management software (HVAC, plumbing,
electrical, landscaping). Published pricing in CAD, live app at `app.astragalhq.com`, footer
"© 2026 Astragal". Domain created **2026-07-28**; private beta and effectively unindexed.

- **No registered mark.**
- **Different goods, channels and buyers** from WordPress plugins and developer tools — which is
  what likelihood-of-confusion turns on. Coexistence of two unrelated software products sharing a
  common noun is ordinary.
- **Residual risk:** if they grow and file in Class 9/42 first, they take priority over a later
  filing. Small and slow — closed cheaply by filing (below).

### Domains

`astragal.com` held since 1999, all transfer locks set — unobtainable. `astragalhq.com` is the
namesake's. **`astragalsoftware.com` is ours.** Free as of the last check: `astragal.dev`,
`astragal.software`, `getastragal.com`, `astragallabs.com`.

## Actions

1. **File intent-to-use, Classes 9 and 42, both names.** Both classes are empty for both marks.
   This closes essentially all the tail risk and is the single highest-value action.
2. **Add CIPO (Canada)** for Astragal — the namesake prices in CAD.
3. **Take `astragal.dev` and `getastragal.com`.**
4. **Date-stamp first use in commerce** for both names. Common-law rights accrue from use; a
   dated record makes them provable.
5. **Do not file Astragal in Class 41.**

## Gaps — what this check does *not* cover

Stated plainly so nobody treats this as more than it is.

- **EUIPO, UKIPO, IP Australia: not searched.** All are JavaScript-gated and were unreachable.
  Matters only if you distribute or market in those territories.
- **Design-mark and full phonetic sweeps.** Word-mark searches were run on the official register;
  MULLIN was checked as the nearest phonetic variant. MULLEN, MULION and design-mark searches
  were not.
- **Mullion, Inc. (NH) status.** Whether the entity is dissolved or still using the name in
  commerce is unverified — this is the one item worth a lawyer's time on Mullion.
- **Common-law use by the astragalhq.com operator.** The registrant is Cloudflare-shielded and
  the site names no legal entity. Establishing their first-use date is the highest-value item on
  Astragal, and a standard knockout search would miss them entirely — they are unindexed.
